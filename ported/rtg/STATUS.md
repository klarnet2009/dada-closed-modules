# rtg - EQUIVALENT (compare_ko.py all OK: 13 functions, 5 exports + CRC, 20 imports, modinfo)
Reference: OS4 stock `vendor_ramdisk/rtg.ko`. Reconstructed from disassembly + BTF; `perf_actuator_clear_rtg` follows the XRING template `dijun-v-oss:xring-modules/drivers/cpu_sched/walt/xr_walt.c`. Kleaf DDK ThinLTO build `g1_tools/bz.sh rtg`; providers plat_common/perf_actuator as generated CRC stubs (`stubs_g1/os4`). Header `rtg.h` has the OS4-extended `struct walt_related_thread_group` (104 bytes: base = MiCode dada `include/linux/sched/walt.h`, plus `rtg_prefer_cpus` cpumask at +88 and `rtg_util` u64 at +96 from the stock BTF; the stock tests the mask with 32-bit loads, i.e. `(u32)bits[0]`) and the ioctl structs (`_IOW('x', 2/0x25/3/4/7, ...)`).
What it does: registers 5 perf_actuator ioctls (set task rtg, set task array (<=15 pids; nr > 15 returns -EFAULT) rtg, set rtg prefer cpus, set rtg util (clamped to 1024), clear rtg) and exports 5 GPL helpers `os_cpu_*` for the scheduler; group id 1 (default coloc) and ids >= 20 are rejected.
Documented hacks: the export CRCs of `os_cpu_get_group_prefer_cpus/_util`, `os_cpu_is_task_prefer_cpu`, `os_cpu_can_migrate_task` (all take `struct task_struct *`) could not be reproduced by any prototype spelling; they are forged with a GENKSYMS-ONLY extra parameter `struct fcrcXXXXXXXXXX *` (macro `GKPAD` in rtg.c, compiled out) whose tag was computed with `g1_tools/crcpad.py` (affine CRC trick, needs one Bazel build to read the built CRCs). `os_cpu_init_rtg_grp_prefer_cpus` (u8 arg) matches without a pad.
