What the engine does: `cpu_states[32]` (40 B: cpu, cluster_id, runq_count, skip flag +0xd, last_jiffies, low_since ktime +0x18, state +0x20, unchanged_ticks +0x24) and `cluster_states[8]` (128 B: cluster_id, cpu_mask(ulong, set_bit in init) +8, active_cpus +0x10, power_save +0x14, min/max/cur freq, freq_pending +0x24, target_freq +0x28, num_cpus +0x2c, mid_cpus = 3/4*num_cpus +0x30, `struct freq_qos_request` +0x38 (64 B with the ANDROID_OEM_DATA word), qos_init +0x78, saved_max +0x7c). `init_module`: cluster id = `cpu_topology[cpu].cluster_id` (package_id if -1), max 8 clusters, per-cluster cpu mask, clusters with <= 2 CPUs are skipped (cpu `skip` flag), per-cluster `freq_qos_add_request(&policy->constraints, FREQ_QOS_MAX, INT_MAX)`, `init_active_cpus_from_runqueues`, DDR voter `sched_entity_freq` (qcom_dcvs_hw_minmax_get DDR, defaults ddr_min_freq / x10, low vote = min, high vote = max, `qcom_dcvs_register_voter(name, DCVS_DDR, DCVS_FAST_PATH)`), workqueue `sef_freq_wq` (WQ_HIGHPRI), sysfs init (failure is non-fatal), `register_trace_android_vh_scheduler_tick(sched_tick_hook)`, `module_ref_count` atomic. `sched_tick_hook` (per CPU, per tick): ignores CPUs of skipped clusters; unchanged runq count -> `unchanged_ticks` saturating counter; on a change: runq == 1 while POWER_SAVE for > 6 ms (`low_since`) or runq >= active_threshold -> CPU ACTIVE, then if the cluster is in power save and active_cpus >= (cluster_active_threshold override or num_cpus/2+1) -> cluster ACTIVE, target INT_MAX, queue `cluster_freq_work`; runq <= idle_threshold while ACTIVE -> CPU POWER_SAVE, then active_cpus <= (cluster_idle_threshold override or num_cpus/2) -> cluster power save, target min_freq, else active_cpus <= mid_cpus -> target mid_freq; `fast_switch_cluster_freq` (cpufreq_driver_fast_switch on the first CPU with a policy) + queue_work. `cluster_freq_work_handler`: per cluster with freq_pending: min/mid target -> remember `policy->max` in saved_max and apply the target through freq_qos MAX request; any other target -> restore saved_max if the current max equals min_freq, else INT_MAX; afterwards the DDR voter gets the low vote when ALL clusters are in power save, else the high vote (`qcom_dcvs_update_votes(name, &cur, 1, DCVS_FAST_PATH)`). `sched_entity_freq_enable(bool)`: sets config.enabled, enable -> `init_active_cpus_from_runqueues`, disable -> reset all cpu/cluster state, flush workqueue, qos max = INT_MAX, `Feature enabled/disabled`.

Lessons: (1) array-bounds traps tell the access form: `cmp idx,#N; b.hi/hs` strict = `array[idx].field` accessed directly, a one-past-end form (`cmp idx,#N+1`) = `&array[idx]` pointer taken first; use `cpu_states[cpu].x` (no local pointer) when the stock has the strict check. (2) Early-exit exports must be written `ret = 0; if (cond) { ...; ret = ...; } return ret;` to get the stock's layout (fixes `get_runq_count` / `is_power_save_mode`); `if (x) return 0;` gives a different block order. (3) `for_each_possible_cpu`, `for_each_set_bit(cpu, &mask, 32)` and `find_first_bit(&mask, 32)` on a 64-bit `cpu_mask` reproduce the stock's `lsl/ands/rbit/clz/csel` loops (GKI has NR_CPUS=32).
