## What changed against the template (all from the stock BTF/disassembly)
- `struct tcm_dev`: new member `write_message_timeout` (+896) and `syna_tcm_v{1,2}_write_message_timeout` (template body made `__always_inline ..._common(..., timeout_ms_resp)` with two wrappers; the response timeout is a parameter, default `CMD_RESPONSE_TIMEOUT_MS`). `set_ops` assign `write_message` first, then `write_message_timeout`.
- `struct syna_tcm`: `int fingerprint_authstate` after `fod_finger`; the last member is `struct dev_pm_qos_request dev_pm_qos_req_irq` (80 B, unused) instead of `pm_qos_request`; all top-level offsets and the size 1976 now equal the stock BTF (`tcm_dev` 1000, `syna_hw_interface` 336, `testing_hcd` 544 also equal).
- Removed XRING-only thermal code (`syna_set_thermal_temp`, `enable_temperature_detection_func`, `get_bms_temp_common`, `add_common_data_to_buf` are not in the stock) under `#ifdef TOUCH_PLATFORM_XRING`; `MAX/MIN` `#undef` before the local macros (kernel minmax.h defines them).
- `syna_dev_set_up_app_fw`: bootloader branch reports `xiaomi_touch_mievent_report_str(0x365c0fb9, 0, "TpIcInBootLoader", "synaptics")` when `firmware_flashing == 0`.
- HACK (names only, no code effect): `syna_spi_device`, `syna_spi_driver` (`...llvm.1283843656653618756`) and `xiaomi_bdata` (`...llvm.66912581257135203`) are non-static hidden objects with the stock ThinLTO-promoted names via `__asm__`.
