# mi_perf_memory - EQUIVALENT

`compare_ko.py`: 21 functions bytes + relocations identical, global objects, imports + CRCs (33), modinfo identical; no exports.

What it is (Xiaomi "mi memory" by zhangcang): `/proc/lowmemorykiller` event file (seq_file + poll), sysfs groups `/sys/kernel/low_free/{low_free_enable,low_free_parm}`
and `/sys/kernel/mi_reclaim/{greclaim_enable,event,madvise_interrupt,greclaim_parm}`, the global reclaim worker `do_reclaim()` (proactive
`try_to_free_mem_cgroup_pages(NULL, 2560 pages, GFP_KERNEL, MEMCG_RECLAIM_MAY_SWAP)` loop driven by anon/file thresholds) and three
vendor-hook probes (`android_vh_tune_scan_type`, `android_vh_shrink_slab_bypass`, `android_vh_throttle_direct_reclaim_bypass`) that let
realtime tasks and a few app processes (`MiuiIntegratedM*`, com.miui.home, surfaceflinger, .globallauncher, system_server) skip throttling/slab shrink.

Recovered `struct mi_memory` (208 bytes, `g_memory`, reached via `pg_memory` pointer): see mi_perf_memory.c. Bits of `greclaim_enable` (7 after init):
0x2 global reclaim enabled, 0x4 server-app tuning enabled, 0x10 / 0x20 log flags. Atomic fields are `atomic_t` (READ_ONCE under LTO gives `ldar`).

Things that were needed for byte identity
- `copts = -ffunction-sections -fdata-sections`, `CONFIG_LTO=1`; lockdep keys of `mutex_init`/`init_waitqueue_head` share one section (see macro in the .c).
- Xiaomi's kernel `poll_wait()` has no trailing `smp_mb()` (the GKI headers on the build server do): `mi_poll_wait()` copy. => the stock headers
  (`work/srcsurvey/micode_dada`, Xiaomi dada kernel) can differ from `<build-dir>`; check them when a tiny inline differs.
- Hook probes: the prio check must compile to `cmp #99; b.le` (not `cmp #100; b.lt`). That only happens when the "hit" block is the layout successor
  of the compare in the IR at ISel time. With a plain `if (rt_task(p) || a || b)` LLVM's late SimplifyCFG (sink of identical stores) moves the hit block
  behind the chain. Reproduced with `if (rt_task(p)) { hit: X } else if (a || b ...) goto hit;` (hit block textually first; also first test jumps into it).
  `tune_scan_type` instead needs the duplicated `if (rt_task(p)) {X} else if (names) {X}` form (its X has a conditional printk, so it is not merged).
- `do_reclaim`: stat reads are volatile asm (`global_node_page_state` = clamped `atomic_long_read`), so source order of the reads decides instruction order:
  start block reads (inactive_file, active_file, inactive_anon, active_anon, cma_free, free); end block reads (..., free, cma_free).
  `loops = reclaim_total / 10` without `max()` (the `bic` clamp is generated by the loop), `reclaim_total = min(reclaim_total, 1024)`.
- `lmk_event_show()` zeroes the event counter before `seq_printf`.
